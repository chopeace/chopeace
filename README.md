## Hi, I'm Peace Cho

Senior software engineer in Toronto. 8+ years shipping production iOS apps (FinTech, Smart Car, Smart City), now building LLM agent systems end to end.

### What I'm building

**[Peace Media](https://chopeace.github.io/peace-media/)**: an agentic pipeline that turns new AI research papers into fact-checked explainer videos every day.
LangGraph script agent with a rewrite loop, fact-checking against paper text and figures, SQLite checkpoints and human approval for new formats; an analytics agent feeds YouTube retention back into the next scripts.
89 videos in the first 18 days on [@PeaceAIBriefing](https://www.youtube.com/@PeaceAIBriefing). [Architecture](https://chopeace.github.io/peace-media/ai-briefing.html)
